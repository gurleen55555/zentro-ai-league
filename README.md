# Zentro AI — Business Operating System

## Overview

Zentro AI is an AI-powered Business Operating System that helps organizations unify customer intelligence, revenue insights, meeting intelligence, and operational decision-making into a single platform.

Modern businesses often operate across disconnected CRMs, spreadsheets, emails, support tools, and meeting platforms. Zentro AI connects these data sources and transforms them into actionable business intelligence through specialized AI agents.

---

## Problem Statement

Businesses struggle with:

* Scattered customer and revenue data
* Poor visibility into high-priority opportunities
* Manual analysis of meetings and customer interactions
* Delayed identification of revenue risks
* Lack of centralized business intelligence

Zentro AI solves these challenges through a unified intelligence layer.

## Installation

Clone the repository:

```bash
git clone <repository-url>
cd zentro-ai
```

Install dependencies:

```bash
npm install
```

Configure environment variables:

```env
NEXT_PUBLIC_SUPABASE_URL=your_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
```

Run locally:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
